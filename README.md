<h3 align="center">Always shipping something.</h3>

I spend my days gluing Linux, Docker and Kubernetes together until deploying stops being scary and starts being boring — the good kind of boring. Most of what I build is automation: Terraform that draws infrastructure instead of describing it in a wiki, GitHub Actions that catch my mistakes before my teammates do, and Bash scripts that exist purely so I never type the same command twice. If it can be containerised, scheduled, or handed off to a robot, I'm probably already halfway through doing it.

#### What I do

- 🔭 Chasing a Terraform plan that finally says 'No changes.'
- currently deep in container orchestration
- keeps notes about automation that will never be published
